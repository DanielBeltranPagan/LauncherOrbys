# Launcher Orbys

Un launcher personalizado para Android centrado en la simplicidad y el control del sistema.

## Características principales
- **Gestión de aplicaciones**: Listado dinámico de apps instaladas.
- **Grabación de pantalla**: Servicio integrado para capturar vídeo y audio.
- **Control de permisos**: Interfaz guiada para configurar permisos críticos de accesibilidad y sistema.
- **Integración con el sistema**: Control de brillo, volumen y conectividad.

## Documentación Técnica
Este proyecto utiliza **Dokka** para la generación de documentación. 
Puedes generarla ejecutando:
`./gradlew :app:dokkaGenerate`
